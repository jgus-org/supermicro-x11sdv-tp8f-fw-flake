Nothing vendor-authored is committed here: the SUM tarball and the firmware bundle are fetched from Supermicro when their packages are built, so evaluating or promoting this repository conveys nothing. Publishing a built `sum` or `firmware` output to a binary cache does convey those vendor images to whoever can read that cache. `sum` and `product-key-tool` are executables this flake builds, `firmware` is the image payload they flash, and all three are declared `unfree`; the flake grants `allowUnfree` in its own package set because the targets it publishes are built here, so no consumer package set is left to make that choice.
