| ----------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| This flake: the Nix, the `smc-*` shell helpers, these documents                                                                                       | [MIT](LICENSE.md)                                                                                                                                                                                                                                                                                                                             |
| [Supermicro Update Manager](https://www.supermicro.com/en/solutions/management-software/supermicro-update-manager) `2.15.0`, the Linux x86_64 tarball | Supermicro's own prebuilt binary, fetched from Supermicro. No licence text ships in the installed output and none is stated at the URL it is fetched from; this flake declares it `unfree` rather than naming vendor terms it has not read                                                                                                    |
| X11SDV-TP8F software package `2.2_AS01.74.13` — BIOS `2.2` (2024-09-03) and BMC/IPMI `01.74.13` (2023-08-02) images                                   | Supermicro's own images, fetched from Supermicro's softfiles host. The two readmes that ship inside the bundle state no terms, and none are stated at the URL; this flake declares the bundle `unfree`                                                                                                                                        |
| [zsrv/supermicro-product-key](https://github.com/zsrv/supermicro-product-key) `v1.2.0`, the `product-key-tool` build                                  | The tag ships no licence file at all. Its `pkg/crypto/README.md` states that directory is a copy of code from the Go 1.21.4 SDK, modified for signature verification, and the Go headers in it say the code is governed by "a BSD-style license that can be found in the LICENSE file" — the file that pointer names is not in the repository |
| `ipmitool`, `pciutils`, `dmidecode`, `python3`, the Go toolchain and the rest of the runtime closure                                                  | As nixpkgs records each one in `meta.license` at the revision this flake locks, where `free` and `redistributable` are separate properties                                                                                                                                                                                                    |

Nothing vendor-authored is committed here: the SUM tarball and the firmware bundle are fetched from Supermicro when their packages are built, so evaluating or promoting this repository conveys nothing. Publishing a built `sum` or `firmware` output to a binary cache does convey those vendor images to whoever can read that cache, and the license acceptance this flake sets in its own package set is what lets the build run at all.
